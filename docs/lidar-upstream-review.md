# 当前雷达实现与上游边界

来源是官方统一驱动 V5.1.3 的固定提交 `ecd9a836`，完整来源及裁剪范围见 [UPSTREAM.md](../src/lslidar_driver/UPSTREAM.md)。2026-10-06 按统一硬件收缩为当前 N10Plus 串口实现。

当前保留 108 字节双回波解码、顺时针角度转换、540 格最近回波输出、完整帧独立发布、串口分段读取和传输失败处理。移除其他型号、网络 / PCAP、矩阵变换、设备时间、MultiEcho 输出和自定义设备服务。原始协议包不经过 ROS 消息生成，只使用固定长度数组。

接口统一为标准 LaserScan、PointCloud2 和 `/motor_control` 的 Int8 输入。部署仅配置串口路径、话题、坐标系和距离过滤；硬件协议变更应修改具体驱动，不使用自动识别或错误参数降级。

本轮软件回归见 [减法记录](hardware-simplification.md)。构造包和伪终端不能替代真实雷达型号、固件、采集时序与板端实时性验证。
