# 激光测量、共享证据与图求解合同

本设计用于 GPU 工程中的建图和定位链路。它定义代码能保证的几何、信息来源及数值性质；不把内部目标下降当成真实轨迹误差下降。

## 测量与搜索先验

轮里程计或已有图位姿可以生成搜索范围和初值。搜索中心的距离、角度惩罚属于搜索偏好；将它乘进匹配响应，会让得到的均值和协方差继续依赖该偏好。当前后端没有独立显式 wheel/odom 因子，不能仅凭这种依赖就断言同一概率先验已经在后端被乘了两次。已证实的是搜索偏好影响了被称为观测的匹配结果；分离接口本身不保证 MSE 降低。

生成图观测的接口应使用命名明确的激光测量目标，响应、均值和局部协方差均从无搜索惩罚的相关栅格提取。旧的先验加权匹配保留显式兼容入口。有限搜索窗口和离散栅格仍会产生截断、选峰和采样偏差；去掉响应惩罚不意味着测量已经无偏或协方差已校准。

## 坐标与协方差

匹配器的随机变量是世界坐标中的激光位姿，图节点的随机变量是车体位姿。设激光外参为车体下的位置 ℓ 和航向 ψ，则 θ_B=θ_L−ψ，p_B=p_L−R(θ_B)ℓ。均值转换时，协方差必须经过完整雅可比

`J_LB = [[I, -R(θ_B) J₂ ℓ], [0, 1]]`。

随后才按 source 车体姿态旋转到相对因子的残差坐标。XY–yaw 交叉项不能丢失；对角线正定也不能替代坐标正确性。这里的前端协方差仍是固定参考状态下由匹配响应得到的局部近似，并非经过物理覆盖率标定的传感器协方差。

## 一个观测只有一个证据身份

原始来源由传感器和原始整数时间标识；准备视图另带几何版本、参考时刻及时间映射。匹配测量身份还包括实际参考来源与线性化位姿、匹配目标和参数、搜索条件。顺序边、近链边、回环边只是路由标签，不会创造新的独立观测。

同一匹配结果投影到另一个 anchor，不得增加一份独立信息。证据 owner 随实际存活图边保存、加载、移除和重建；旧归档缺少身份时标记为未知，不能补造独立性证明。身份采用完整内容比较，短哈希只用于审计摘要。

不同身份也可能共享 query、参考扫描、运动或标定误差。精确去重只消除已知重复，不证明其余因子独立。

## 同一 query 的候选融合

当前实现中的 CI 是前端发布/后续搜索状态的提案启发式。后端仍保留各个相关候选因子，融合协方差没有进入后端联合因子；因此不能称后端已通过 CI 处理同 query 的相关性。候选先进入同一、由匹配前参考位姿定义的 SE(2) 局部 chart，均值和协方差一起变换。对未知交叉协方差的同一状态估计使用 covariance intersection：权重非负、总和为一，以信息矩阵的 log determinant 决定权重；不使用 GT，也不分别给平移和航向使用互相矛盾的均值规则。

重复证据去重、候选排列和等信息的 tie 规则必须保持确定性。角度跨切口、无单值 chart、非法协方差均显式处理。CI 的真实协方差保守性要求输入边际本身相容；当前响应协方差未校准，代码只能保证相应代数合同。320 次原生 matcher 试验的输入是合成几何：预设共享扰动下名义 95% 覆盖约 25–37.5%，这是对该模型的有效反例，并不是对真实 LILocBench 序列物理覆盖率的测量；不能由它拟合真实数据的膨胀倍率。该方法的适用对象是同一 query 状态，不是完整图联合似然。[原始 SLAM/CI 文献](https://doi.org/10.1016/j.robot.2006.06.011)

## 未知相关性和运动不确定性

若误差依赖图完整、非邻块确实条件独立，且每块协方差由 P_i 上界，则对 degree 为 d_i 的块有联合上界 `Cov(e) ≼ blockdiag((d_i+1)P_i)`。此界可由白化交叉块范数及 `2ab≤a²+b²` 推导。仅有来源标签不足以证明非邻独立；缺失运动、搜索或标定祖先时不能假设它们不存在。完全未知的全局相关性退化为共同倍率，不会自动改善点解。

当前去畸变对给定 TF 轨迹作确定性条件变换。消息中固定的 pose/twist 边际协方差没有提供跨时间及参考位姿与帧内运动的交叉协方差，不能直接拼成短时过程噪声。map/query 合同和实际诊断明确标记 `conditional_not_marginalized`、`temporal_covariance=not_supplied` 与来源独立性未知。

未来若引入运动潜变量，必须使用同一个联合运动先验：先给 reference motion 更新一次，再用帧内运动在该 reference motion 条件下的分布进行观测边缘化。不能把同一份轮数据再当成独立去畸变先验相乘。物理时钟与束序仍需独立证据。

## 求解是可验收的事务

冻结因子、gauge 和初值后，分别记录求解前、候选和提交状态。仅在节点有限、anchor 保持、当前真实目标有效且不增加时发布修正；失败、异常或被拒候选恢复原节点值并清空旧修正。不得替换 Ceres 所持指针指向的节点存储。

原生终止原因、逐步变化、自由变量梯度和实际提交代价分开保存。`usable`、事务接受、达到梯度容差是不同状态；以米和弧度求导的混合梯度范数不表示物理定位精度。默认停止设置不因个别测试分数调整。[Ceres 终止状态说明](https://ceres-solver.readthedocs.io/latest/version_history.html)

验收包括独立几何扰动、重复与排列性质、协方差覆盖诊断、冻结目标干预、实际新建图及完整 GPU 定位。独立参考地图上的定位按其公开协议另列；同源地图内自洽不作为真实精度证明。


## 候选、关联、约束和提交分别验收

fine 响应通过仅说明该匹配通过现有响应与几何合同；关联门限、图中新增因素、求解可接受和正式状态提交是不同步骤。匹配在临时视图中进行，接边接口返回结构化的 Added、AlreadyOwned、Rejected 或 Queued 状态与原因。没有新增因素时，不能求解旧图后把它说成该候选成功闭环，也不能将候选暂写到正式 scan 后再依赖旧 solver 状态覆盖。

本轮生命周期修整保留已有距离/响应门限，以及前端 CI 和后端条件二次代理目标，只改变接边到提交的语义。新增因素关联有效但求解被拒时，采用明确的保留因素、拒绝位姿提交策略：因素可供以后求解，当前不发布闭环成功；数值失败不冒充关联失败。注册因素失败则撤回本次未完成注册的 edge、邻接和 owner 变化。普通顺序建图必须传播该错误，不能因调用者忽略结构化返回值而报告 scan 成功；只有可选回环候选选择结构化拒绝。普通入口的 failfast 后要求 Reset，不宣称整个 scan 已恢复为可继续处理的事务。受检拒绝与已测试异常的回滚，不构成任意内存耗尽下的全图强异常保证。

`ScanSolver` 新增因素注册与数值事务的确认接口，默认返回 Unknown；旧插件需要重新编译并实现明确确认和原子求解语义，才能参与自动闭环提交。Ceres 确认实际 residual-map 项及事务接受结果。Unknown 不满足自动闭环状态提交条件；注册确认未知时不会进入该候选的求解。`loop_commit.backend_factor_registered` 表示本次新增因素的确认；AlreadyOwned 时为 false，不表示既有 owner 缺少后端因素。

节点距离仍是启发式的关联保护，不是候选真假标签。本轮不会为了已知第 119/120 帧放宽 1.5m 或改响应门限。几何重叠、重复结构、歧义及参考状态不确定性的关联模型需要另行验证；当前生命周期正确性不能替代它。所有判别均不读取 GT。

2026-10-17 根据新根因分析澄清：搜索依赖不等于已证实显式先验双计数、CI 提案不等于联合后端、合成 matcher 覆盖反例不等于真实序列物理覆盖测量。旧 epoch 的原结果保留，以上是当前解释边界。
