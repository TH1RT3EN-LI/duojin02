# GPU 漂移修正实现

对应 `output/lilocbench-v3-drift-remediation-math-20261016/report.md`。
修改只位于 `duojin02-cuda-local`，包含 GPU 估计器需要的主机端 PF、扫描几何和建图依赖；原 CPU 工作区不参与修改或构建。

| 阶段 | 已落实的生产路径 |
|---|---|
| P0 | 固定版本 `nav2_map_server` 源码补丁进入 SLAM overlay，分别按 float32/double 保存数字精度；图像像素保持相同。 |
| P1 | 保留原始扫描戳、束索引及时间映射来源；运动更新、观测、位姿和 map→odom 使用同一物理参考时刻及 SE(2) 插值。缺失未来 TF 按序等待，超时、内部缺口和不合法输入明确拒绝。 |
| P2 | 建图和 AMCL 共用逐束几何；完整外参和杆臂仅应用一次。AMCL 使用任意 base 端点；Karto 保留逐束端点、移动射线原点、原始量程和时间，支持 dirty 更新、图保存与加载。 |
| P3 | Ceres loss scale 可配置并校验；记录真实接边来源、链成员、测量/协方差、白化残差、核影响及每次优化前后节点状态。默认核和接边门限保持原配置。 |
| P4 | 概率似然场加入 β 接口，默认 1；按源戳记录实际使用束、距离分位数、随机地板比例与 log 因子。未使用 GT 调参。 |
| P5 | log 先验与观测联合归一化、log recovery 平均、显式异常拒绝；ESS/KLD/谱系日志、可选 ESS 门控；主簇均值配同簇完整 3×3 协方差，非重采样帧也重建统计并发布。 |

生产启动仍默认 `scan_motion_compensation: false`、offset 0、首束参考、β 1、ESS 门控关闭，KLD 单 bin 上限、严格 `N > limit` 停止规则和 `pf_z` 的旧分位数数值语义保持。报告中 −110 ms 没有进入默认参数。

## 构建和使用

在已有 Humble/CUDA 依赖的环境中执行：

```bash
BUILD_JOBS=2 BUILD_WORKERS=1 ./scripts/build_slam_backend.sh
BUILD_JOBS=2 BUILD_WORKERS=1 CUDA_ARCHITECTURES=120 ./scripts/build_cuda_local.sh
source ./scripts/source_cuda_local.sh
```

新建依赖镜像的 Dockerfile 同样构建带补丁的 SLAM 和 map server。
开发构建和运行优先加载本工作区的 `install/slam_backend`，GPU 安装仍为 `install/cuda-local-v3`。
源归档、顺序补丁和完整准备树均有哈希验证。测试文件及原始实验结果保留在各自证据目录。

开启补偿前，在建图和定位参数中设置完全一致的时间/几何合同，并从原始扫描重新建图。
新地图随 `<prefix>.scan_geometry.json` 保存合同，快照提交将其一并校验、哈希和发布；定位入口拒绝合同不一致。没有合同的旧地图仅允许旧 D0/identity 解释。
非零 offset 必须同时提供独立命名的 `capture_time_mapping_id` 和非空 `capture_time_mapping_source`。
这些字段记录来源，不能自动认证真实硬件已完成校时。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `scan_motion_compensation` | false | 两端一致开启逐束几何 |
| `capture_time_offset_sec` | 0 | 原始 header 到首束物理时刻的映射偏移 |
| `scan_reference_fraction` | 0 | 参考在首束到末束跨度中的位置，范围 [0,1] |
| `scan_max_tf_gap_sec` | 0.1 | 每条动态 TF 边允许的最大插值间隔；禁止外推 |
| `likelihood_temperature_beta` | 1 | 概率似然场 log 似然倍率，范围 (0,1] |
| `resample_ess_ratio` | 0 | 0 保留旧门控，非零时按观测后 ESS/N 决定是否重采样 |
| `kld_confidence_probability` | -1 | -1 保留旧合同；(0,1) 显式转正态分位数，与显式 `pf_z` 互斥 |
| `filter_diagnostics_log_every` | 0 | 源戳对应的 PF/观测摘要日志间隔，0 关闭 |
| `ceres_loss_scale` | 0.7 | 白化残差中的无量纲鲁棒核尺度，必须正且有限 |
| `ceres_diagnostics_path` | 空 | Ceres/接边事件 JSONL 路径，空关闭 |

## 根因复核后的扫描合同修复

第二轮依据 `output/lilocbench-remediation-root-cause-20261016/report.md`

反推有效性。有限的 0/0.002m、NaN、负无穷和超传感器量程束不参与匹配或清空空间；
合法无返回仅按明确政策清空空间。算法门限仍独立筛选并记录原始束索引。

## 测量与共享证据模型 epoch

用户要求的方法应对模型本身负责，不能按某次测试的时间窗口、source ID 或 GT 输出打补丁。
该 epoch 将图匹配入口明确分成激光响应与搜索偏好：生产图测量使用 `MatchLidarEvidence`，
距离和角度的 prior 惩罚不再乘进所称的激光响应。轮运动和历史状态仍用于初值、有限搜索
支持及去畸变。后端没有独立显式 wheel/odom 因子，不能把这项语义分离称为已证实的
概率先验双计数修复。有限窗口与离散选峰仍可能有偏；相关分数不是已校准的物理似然。

实现完整 sensor→base 杆臂雅可比与后续 source 残差坐标传播，保留 XY–yaw 交叉项；
同 query 多候选进入同一 SE(2) chart 后作确定性的 covariance intersection。
同一个实际测量投向其他 anchor 时只保留一个活跃证据 owner。身份使用完整 context、
准备视图字节和原始来源作精确比较，短 hash 仅用于审计。新 LinkInfo v2 归档保留身份，
旧 v1 图仍可读取并明确标记 unknown_legacy。跨 query/reference/motion 的相关性仍未知。

Ceres 提交增加事务验收：独立计算实际初始/候选/提交目标与自由梯度，检查有限值、固定
anchor 和不增的目标；失败、异常及拒绝回滚并清除旧 corrections。usable、accepted 与
stationary 分开报告。六个冻结旧事件的 24 次同目标求解中，更充分降低原目标均未改善 GT，
