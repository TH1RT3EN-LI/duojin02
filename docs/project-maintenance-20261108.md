## 进程清理修正

在非特权、撤销全部 capabilities 的容器中，离线回放的子进程收到终止信号后，Linux 可能先
禁止读取 `/proc/PID/environ`，约数毫秒后才把进程状态标为 zombie。原清理逻辑在这段间隙
报告无法核验会话成员，使真实孤儿进程回归失败。

现在只对本会话中遇到该错误的进程等待最多 50 ms，并反复确认进程已退出或进入 zombie。
持续存活但无法核验的进程仍导致错误。新增回归验证这种存活进程不会收到清理信号；
原有真实孤儿、单次中断转发、身份篡改检查继续运行。
